Pen: CSS 3D Solar System

by Julian Garnier

This pen is a 3D model of the solar system, with the sun and all eight planets. It has a Data menu with info on each planet and a Controls menu for changing the view and speed. I picked it because it looks great and shows how much you can do with CSS.
